# Movie Database App (Android)

An Android app built in **Kotlin** that browses movies from a public movie database API, featuring list and detail screens with poster image loading and an MVVM structure.

## Features
- Browse popular / now-playing movies
- View details for each movie (overview, rating, release date)
- Poster image loading for a rich list UI

## Tech Stack
- **Language:** Kotlin
- **Architecture:** MVVM
- **Networking:** Retrofit (REST API)
- **Async:** Coroutines & Flow
- **Build:** Gradle (Kotlin DSL)

## Getting Started
1. Clone: `git clone https://github.com/Muhammad-Umer-Android/MovieDbApp.git`
2. Open in Android Studio, add your movie database API key (e.g., TMDB), and let Gradle sync.
3. Run on an emulator or device.
